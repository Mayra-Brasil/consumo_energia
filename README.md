# **Cálculo de custo energético por elétrodomésticos** 🪫

Esse programa feito com **Python** tem como objetivo cálcular o consumo mensal energétivo de um aparelho, sendo essencial as informações da potência em watts (W) e oa quantidade de horas utilizada por dia!

Tal atividade foi desenvolvida á partir da agenda 5 da matéria de Desenvolvimento de Sistema!
